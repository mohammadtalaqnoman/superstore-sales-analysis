# Superstore Sales Analysis

Analyzed 10,800 orders from Superstore sales data using Python (Pandas, Seaborn) and Excel to uncover revenue trends, seasonality, and profit loss areas.

### What I Did
1.  **Data Wrangling:** Removed 504 duplicate rows and handled 806 missing values.
2.  **Feature Engineering:** Created new columns - Year, Month, Year_Month, and Profit Margin %.
3.  **Analysis:** Analyzed Customer Purchase Volume, Monthly Seasonality, Category-wise Revenue, and Discount Sensitivity.

### Key Findings
- **Technology is the Revenue Leader:** Generated 8.36 Lakh in sales, highest among all categories.
- **Furniture Has Low Profitability:** Despite 7.42 Lakh in sales, profit margin is only 2.49%.
- **Tables Are in Loss:** Tables category faced a loss of -17,725.
- **Seasonality Exists:** Sales peak in July and Nov-Dec, while February has the lowest sales.
- **Discount is Eating Profit:** 0% Discount gives 29.5% margin, but discount above 20% leads to loss.

### Tools Used
Python, Pandas, Seaborn, Matplotlib, Excel
